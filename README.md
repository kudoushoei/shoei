# 体づくりログ

iPhoneの「ヘルスケア」アプリのデータ（体重・体脂肪率・歩数・消費カロリー・睡眠）を取り込んで、
食事(カロリー/PFC)の記録と合わせて体づくりの進捗を見るための個人用Webアプリです。

- ビルド不要（Node.js等が無い環境でもそのまま動きます）。素のHTML/CSS/JSのみ。
- データはすべて**ブラウザ内のIndexedDBに保存**され、外部サーバーには一切送信されません
  （食事写真の栄養解析だけは、ユーザー自身のAPIキーで直接Google Geminiに送信されます。後述）。
- スマホの「ヘルスケア」との自動同期（リアルタイム連携）はできません。ヘルスケア側の
  「すべての健康データを書き出す」機能を使って、手動でファイルを取り込む方式です。
  （iPhone上でネイティブにHealthKitへアクセスするには本来Apple Developer登録とMac/Xcodeが
  必要になるため、無料・Windows環境という制約に合わせてこの方式にしています）

## 使い方

### 1. iPhoneのヘルスケアデータを書き出す（PC不要、iPhone単体でOK）
1. iPhoneで「ヘルスケア」アプリを開く
2. 右上のプロフィールアイコンをタップ
3. 一番下までスクロールし「すべての健康データを書き出す」をタップ（`export.zip` が作成されます）
4. 「”Files”に保存」でiPhone内に保存

展開は不要です。次の手順でこの `export.zip` をそのまま選べます。

### 2. アプリで取り込む
「取込」タブで `export.zip`（または展開済みの `export.xml`）を選択すると、
アプリ内でZIPを自動展開し、体重・体脂肪率・歩数・消費カロリー・睡眠時間が
日付ごとに集計されて保存されます。データ量が多いと数十秒かかることがあります。

### 3. 食事を記録する
「食事」タブで食品名・カロリー・P/F/Cを手入力するか、「写真を撮る/選んでAIに解析させる」から
写真を撮ると、Gemini APIが内容を見て栄養価を自動推定し、フォームに入力してくれます
（内容を確認・修正してから「追加」を押してください。あくまで目安です）。

写真解析を使うには「設定」タブでGemini APIキーの登録が必要です（後述）。

食物繊維・糖質・塩分・カルシウム・鉄分・カリウム・ビタミンCなど、カロリー/PFC以外に
気にしたい栄養素も「設定」タブから選んで追跡でき、目標に対して不足している場合は
「不足」表示が出ます。

### 4. 目標を設定する
「設定」タブで身長・年齢・活動レベル・目標（減量/維持/増量）を入力すると、
必要カロリー・PFCが自動計算されます（Mifflin-St Jeor式）。手動で数値を直接設定することも可能です。

### 5. 写真からの栄養推定を使う（任意）
1. [Google AI Studio](https://aistudio.google.com/) にアクセスし、「Get API key」から無料でAPIキーを発行する
2. アプリの「設定」タブ →「写真からの栄養推定 (AI)」でそのキーを貼り付けて保存
3. 「食事」タブの「写真を撮る/選んでAIに解析させる」から使える

APIキーはこの端末のブラウザ内(IndexedDB)にのみ保存され、Google以外には送信されません。
Gemini APIは無料枠の範囲であれば料金はかかりません（利用量が多い場合は上限に達することがあります）。
写真からの推定値は目安であり、実際の栄養価とはズレることがあります。

## ローカルで試す（このパソコンだけで使う場合）
`index.html` をブラウザで直接開くだけで動作します。ただしこれだと自分のiPhoneからはアクセスできません。

## iPhoneで使えるようにする（無料ホスティング）
iPhoneのSafariから使えるようにするには、どこかに公開してURLを発行する必要があります。
Node.js等のビルドツールは不要なファイル一式（このフォルダそのまま）なので、以下のような
無料サービスにそのままアップロードできます。希望があれば公開作業もお手伝いします。

- **GitHub Pages**（推奨）: GitHubアカウントがあれば無料・無期限。このフォルダをリポジトリに
  push して Settings → Pages で有効化するだけ。
- **Cloudflare Pages** / **Netlify**: アカウント登録すればドラッグ&ドロップでも公開可能。

公開後、iPhoneのSafariでURLを開き、共有ボタン→「ホーム画面に追加」をすると、
アイコンをタップして普通のアプリのように起動できるようになります（オフラインでも動作します）。

## データのバックアップ
「設定」タブの「バックアップを書き出す(JSON)」でエクスポート、「バックアップを読み込む」で復元できます。
IndexedDBはブラウザ・端末ごとのデータなので、機種変更やブラウザのデータ削除に備えて
定期的にバックアップを取ることをおすすめします。

## 今後の拡張について
「ヘルスケアとリアルタイム自動連携したい」「友人にアプリとして配りたい」となった場合は、
Expo(React Native) + HealthKit連携でネイティブアプリ化する道があります。ただしその場合は
Apple Developer Program登録（年額約1.4万円）が必要になります。
